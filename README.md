## 프로젝트 구조

```
desktop-tutorial/
├── index.html              # 메인 페이지

│   ├── hero-city.jpg       # 폐허 도시 히어로 이미지

├── videos/
│   ├── trailer.mp4         # 공식 트레일러 (추가 필요)
│   └── gameplay.mp4        # 게임플레이 영상 (추가 필요)
└── README.md
```

---

## 영상 추가 방법

1. `videos/` 폴더에 영상 파일 추가:
   - 트레일러: `videos/trailer.mp4`
   - 게임플레이: `videos/gameplay.mp4`

2. 파일 이름이 다른 경우 `index.html`의 `<source src="...">` 경로 수정
